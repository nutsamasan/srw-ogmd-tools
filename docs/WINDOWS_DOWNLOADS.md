# Windows downloads

Open [the latest release](https://github.com/nutsamasan/srw-ogmd-tools/releases/latest) and expand **Assets**. Download one `windows-x64.zip` for the tool you want. Each tool's data is included. Files called **Source code** are for development.

| Complete download | Tool | Open after extracting |
| --- | --- | --- |
| `OGMD-Save-Editor-1.6-windows-x64.zip` | Save Editor 1.6 | Its `.exe` |
| `OGMD-Pilot-Editor-1.1-windows-x64.zip` | Pilot Editor 1.1 | Its `.exe` |
| `OGMD-Mech-Skill-Patcher-1.0-windows-x64.zip` | Mech Skill Patcher 1.0 | Its `.exe` |
| `OGMD-Script-Editor-3.16-windows-x64.zip` | Script Editor, corpus, previews, built-in patcher data | `Start Script Editor.cmd` |
| `OGMD-Full-English-Patcher-1.6.3-windows-x64.zip` | Full English Patcher and complete patch data | Its `.exe` |

1. On 64-bit Windows 10 or 11, right-click the downloaded ZIP and choose **Extract All**.
2. Open the extracted folder and launch the tool listed above.
3. Keep all included folders together. Python is included; no separate installation or data download is needed.
4. Choose your own supported game/save input when editing or patching. Keep backups before saving changes.

The Script Editor finds the included corpus and preview resources. Its built-in Full English Patcher also has its data included. The standalone patcher finds its `data` folder beside the EXE. See [complete package setup](DATA_DOWNLOADS.md).

Packages include startup instructions, licenses, and source/build information. SHA-256 hashes are listed in `SHA256SUMS.txt` on the release page. `Dependency-Sources-2026-09-29.zip` is for developers and is not needed to run the tools.
